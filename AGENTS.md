# NexKit repository instructions

Use English for all project artifacts: source identifiers, comments, CLI text,
skills, prompts, documentation, examples, issues, pull requests and release notes.
Conversation with the repository owner may remain in Vietnamese when requested.

Preserve the acceptance criteria and report live integration, live local agent
runs and mocked boundaries separately. Never fabricate a human approval or infer
permission to publish a public release from permission to prepare a candidate.
